# Asset register

Keep originals in `inputs/` and derived files in `assets/`. Add one record per asset.
Record actual rights and required credits; the repository code license does not
automatically cover logos, photos or fonts. Do not put licensed client assets in Git.

- File in `inputs/logos/`:

- Original or derived; preparation history:
- Visual inspection notes:
